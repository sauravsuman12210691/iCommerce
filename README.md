# iCommerce (Frontend)

**iCommerce** is a sleek and responsive iOS e-commerce frontend built using **Swift**. This project showcases a modern shopping UI with product listing, detailed views, and cart interfaces. It is currently focused on the frontend implementation and does not include backend integration.

## 📱 Features (Frontend Only)

- 🛍️ Home screen with product cards
- 🖼️ Product detail view with image, price, and description
- 🛒 Shopping cart UI (add/remove items)
- 🔍 UI for search and filters (static/mock)
- 🧭 Bottom tab navigation (Home, Cart, Profile)
- ✨ Clean and modular UI components

## 🛠️ Tech Stack

- **Language**: Swift
- **Framework**: UIKit / SwiftUI *(choose one based on your UI implementation)*
- **Design Pattern**: MVVM (optional if applied)
- **Navigation**: UINavigationController / TabView
